## The entry

One original one-line joke about office life:

> IT fixed the printer by unplugging it, which is also how HR handles difficult employees.

## How it works

`main.ts` (Node 22, standard library only) writes the joke to `/output/entry.txt`, validating the competition gate first: UTF-8 text, 1 to 200 characters, not only white space.

Run it:

```sh
node main.ts
```

Set `OUTPUT_DIR` to write the entry somewhere else (for example `OUTPUT_DIR=./out node main.ts`).
